# Spike: how Upstash counts Lua scripts, and its budget cap

*Fri 10/16. Part of the day-one spike. Feeds the rate limiter and the meter's cost model.*

## Lua scripts: billed as the script plus every command inside it

Upstash's docs do not say how `EVAL` is billed ([billing](https://upstash.com/docs/redis/overall/billing)). They only say each command inside a pipeline or transaction is billed on its own. `INFO` returns zero counters over REST, so the count was read from the Upstash console instead.

**Method.** Paula read the daily command count on the `corner-office` database, which showed 66. Then 300 `EVAL` calls ran, each doing 10 `INCR` and 1 `GET` inside the script, followed by 1 `DEL`. Paula read the count again once the console caught up.

| If Upstash bills | Expected count | Seen |
|---|---|---|
| Each script as one command | 66 + 300 + 1 = 367 | |
| Only the commands inside | 66 + 3,300 + 1 = 3,367 | |
| The script plus every command inside | 66 + 3,600 + 1 = 3,667 | **3.7K** |

**Result.** A script costs 1 plus the number of `redis.call`s it makes. Atomicity is free, but batching through Lua saves nothing on the bill.

## Budget cap

On pay-as-you-go, a database that reaches its monthly budget is **rate-limited, not billed further**, and Upstash emails at 70 and 90 percent ([pricing](https://upstash.com/pricing/redis)). The docs do not name the error clients see once limited.

## What it means for the build

- **Count every command.** The rate limiter and ledger should count each `redis.call` in a script, plus 1 for the script itself, when estimating cost.
- **Scale.** At $0.20 per 100,000 commands, even 20 commands per visitor run is $0.04 per 1,000 runs, so the $20 minimum budget is far above expected spend.
- **Fail safe.** Any Upstash error must fail safe. The limiter denies, or falls back to replay, rather than letting a run through uncounted, because a budget-limited database may answer with an error we have not seen yet.
- **Console lag.** The console's daily count lagged by about an hour, so it is a check, not a live meter.
