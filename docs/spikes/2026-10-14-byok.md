# Spike: Claude calls on Paula's own key (BYOK) through OIDC

*Wed 10/14. Part of the day-one gateway spike. Feeds ADR 0002 and the secrets table.*

## Setup

- Paula created a `gateway` workspace in the Claude Console with a $1 monthly limit, made a key in it and saved it on the Moontaxi Lab team's AI Gateway BYOK page. The key never left her screen.
- Calls authenticated with a Vercel OIDC token (pulled with `vercel env pull` into a gitignored `.env.oidc`, deleted afterward), with no gateway API key. That is the same keyless path production uses. The token was issued for the development environment, and BYOK is team-wide, so production follows the same route.
- Every call pinned Anthropic as the only host (`providerOptions.gateway`, `order` and `only` set to `["anthropic"]`), as revision 1.2 requires.

## Results

**1. OIDC requests use the team's BYOK key. Pass.** The gateway's routing record says "BYOK credentials available for anthropic", plans the order `anthropic(BYOK) → anthropic(system)`, and reports `credentialType: byok` on the attempt. The gateway charged `cost: 0`.

**2. A request past the limit falls back to Vercel's credentials. Pass.**

| Call | Opus 5.5, 8000 tokens out | Credential | Gateway cost | List price (`marketCost`) | Time |
|---|---|---|---|---|---|
| 1 to 7 | each | byok, 200 | $0 | $0.160 | about 89s |
| 8 | | byok failed with 520, then system 200 | $0.160 | $0.160 | 131s |
| 9 | | byok failed with 400, then system 200 | $0.160 | $0.160 | 92s |

Anthropic let the workspace reach about $1.12 before refusing, an overshoot of under one request. Both later calls succeeded on Vercel's credentials and were billed to the gateway balance at list price.

**3. Receipts can keep list price. Pass, with a field change.** The gateway reports `marketCost` (list price) on every call, BYOK or not, and `cost` is what the gateway balance actually paid ($0 on BYOK). The plan named `isByok` and `upstreamInferenceCost`, and neither field appears. Use these instead.
- **Credential.** The last entry in `routing.modelAttempts[].providerAttempts[]` has `credentialType`, either `byok` or `system`.
- **Receipt and meter cost.** `marketCost`, always.
- **Spend against the gateway balance.** `cost`.

## Things to plan around

- **A failing BYOK attempt can be slow.** Call 8's BYOK attempt failed with a 520 after about 40 seconds before the fallback ran. A visitor's live run with a 55-second ceiling could time out in that case. Once the workspace is over its limit, every Claude call first makes a failed BYOK attempt. The 400 on call 9 failed fast, so the slow case may be a one-off, but the router should log `credentialType` and attempt count on every receipt so we can see it.
- **Right now the workspace is over its $1 limit**, so every Claude call on the team tries the key, fails and falls back. Raise the limit to $60 (the plan's next step) or remove the BYOK key until then.
- **Gateway budgets do not count BYOK spend**, as the docs say. The `gateway` workspace limit and the app's caps bound Claude spend on the key.

## Spend

About $1.12 against the `gateway` workspace (Paula's Claude credit) and $0.32 against the gateway balance for the two fallback calls.

## Verdict

All three checks pass. Per the plan, the `gateway` workspace limit goes to $60 and BYOK stays on before the Wed 10/21 freeze. Paula raises the limit.
